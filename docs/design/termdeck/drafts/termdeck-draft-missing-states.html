Derivation & reviewed decisions
TAKEN FROM THE ACCEPTED EXPORT
Palette: accepted tokens only, no new colours. Accent #2dd4a7, idle border #232830, warning #d8a657, hints #4d555f, keys #8a929c, labels #6d7580, backgrounds #0e1013 / #12151a.
Geometry: 144×42, master 98 / gutter 2 / stack 44, content rows 40, blank row 41, status row 42, previews 12 rows with 1 blank between, 2-col pane padding.
Chrome: titles inside the top border 2 cols from the left, right-aligned slot for the mode tag, reverse-video tag styled exactly like the accepted ZOOM tag, single-weight box drawing, ^g key notation from the status bar.
The scrollback footer reuses the accepted exited-pane pattern verbatim — a rule line followed by a status line, here carrying the navigation keys alone.
05 · HELP OVERLAY
60 cols × 21 rows, centred at col 42 / row 10. The primary bindings and their wording come from PLAN.md. The esc close is not in the plan; it follows the reviewed modal behaviour, matching Escape cancelling the quit confirmation and leaving scrollback.
Q1 accepted. Focus stays singular: the overlay takes the accent border and the master gives its own up.
Q2 accepted. The underlay recedes by foreground-only dimming to #3a424c. The two accepted background values are never supplemented with a scrim.
Q3 accepted. Letter spacing in the export is illustrative web chrome; the TUI does not emulate it. Section headings are accent and uppercase only.
06 · QUIT CONFIRMATION
52 cols × 10 rows, centred at col 46 / row 16. The consequence text is the lifecycle contract from PLAN.md: SIGTERM, two seconds, then SIGKILL.
Q4 accepted. The accent border is kept and the warning hue is confined to the consequence line.
Q5 accepted. y confirms; n and Escape cancel.
Q6 accepted. The box states the number of terminals to be closed, not their names.
07 · SCROLLBACK MODE
A mode of the master pane, not an overlay: previews stay live and the stack is not hidden, because PLAN.md ties hiding the stack to zoom alone. No block cursor is drawn — the viewport is detached from the live tail.
Q7 accepted. Escape exits scrollback and returns to live output.
Q8 accepted. While scrollback is active Termdeck captures j/k, the arrow keys, PageUp, PageDown, g, G and Escape, and must not forward other input to the hidden live shell. This is an explicit exception to ordinary input forwarding while a modal or mode is active.
Q9 accepted. The mode tag keeps the warning colour, so it does not read as ordinary accent focus.
Q10 accepted. Scroll position is stated once. The pane title carries the mode tag alone, the pane footer carries the navigation keys alone, and the absolute position appears in the status line.
FIDELITY LIMITS OF THIS FILE
Self-contained static HTML with no external resources: no fonts, scripts, styles or images are fetched. It deliberately does not use the x-dc canvas format, because the export's support.js fetches React from unpkg.com at load time and so will not render offline. This file opens from file:// with no network.
Type is the platform monospace stack, so glyph metrics differ slightly from the export's JetBrains Mono. Cell counts, not the rendering, are the spec.
Overlay boxes are positioned in ch and 20px row units so the cell grid is exact, but browser sub-pixel rounding may shift a border by a pixel.
Body text is illustrative filler in the style of the accepted screens. Only the chrome — borders, titles, tags, footers, status bar, key hints — is specified here.
