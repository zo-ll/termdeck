Design specification
PALETTE — 16-COLOR SAFE
#0e1013 canvas / pane bg#12151a status bar bg#232830 idle border#2dd4a7 master border / accent#d7dbe0 master foreground#8a929c preview foreground#4d555f timestamps, hints#98c379 running / success#d8a657 warning / slow#e06c6c error / non-zero exit#7aa2f7 URLs#c898e0 tool prefixes ([vite], queue)
Only two background values in the whole UI. Hue carries meaning; nothing is coloured for decoration.
BORDERS & SPACING
Single-weight box drawing throughout: ─ │ ┌ ┐ └ ┘. No double lines, no rounded corners, no shadows.
Master: #2dd4a7 border. Previews: #232830; the pane that was just demoted holds #2a3038 plus a 1-shade lighter bg for ~1.5s, then settles.
Grid 144×42. Master 98 cols, gutter 2, stack 44. Content rows 40, blank row 41, status row 42. Pane padding 2 cols horizontal, 0 rows vertical. Previews 12 rows each, 1 blank row between.
TITLE FORMAT
Master > {n} {name} · {cwd} · {dot} {state} · {cmd}
Preview {n} {name} · {cwd} · {dot}
Titles sit inside the top border, 2 cols from the left. Right-aligned slot carries the activity meter and the MASTER / ZOOM tag.
Paths shorten left-first: ~/idp/frontend → …/frontend → …/frontend. Output lines truncate right-first with …; a wrapped continuation indents 2 cols.
STATUS & ACTIVITY
● running, output within 30s ○ running, idle (age shown: idle 6m) ✕ exited non-zero — ✕ exit 1 ✓ exited zero — ✓ exit 0
Activity is a 6-cell bracket meter, [####··] to [······], redrawn once per second from bytes written. It fills and empties, never blinks, and never moves the cursor.
An exited pane keeps its last output, dims to #6d7580, and gains a footer rule with exited · code 1, the timestamp, and the restart key.
FOCUS & PROMOTION
Four cues fire together so focus never depends on one: teal border, a > caret before the pane number, full-contrast foreground, and the status-bar > pointer.
Promotion is an instant swap — no slide or fade. The selected preview takes the master frame; the old master drops into the slot it vacated so positions stay learnable. Both panes keep scroll position and scrollback.
PICKER — LAYOUT & GLYPHS
Same 98 / 2 / 44 split as the session, so the picker teaches the layout before the workspace exists. Top bar replaces the workspace chip with termdeck; bottom bar carries picker keys instead of session keys. The focused column takes the teal border.
◆ git repository (teal) ▸ folder (amber), ▴ parent · plain file, dimmed, not selectable
Repos carry branch, dirty count (+3), and relative mtime; folders carry item counts and no repos when they contain none. The cursor row prints a three-line detail block at the bottom of the listing rather than a popup.
SELECTION STATES
[ ] unselected [1] selected — the number IS the pane number, and [1] is the master [+] marked to append (runtime add) [·] already open, not selectable
Ordinals do the work a checkmark can't: selection order, pane number, and primacy read from one glyph. Deselecting renumbers immediately; m promotes the cursor row to master, K/J reorder inside the panel.
a selects every repo in the current folder, A recurses the whole root. With nothing selected the launch button renders disabled and ⏎ on a folder navigates instead.
FILTER & EMPTY STATES
/ opens a query line pinned to the bottom of the listing — never a modal. Matching substrings highlight teal; results from other configured roots appear under a labelled rule so a filter is a workspace-wide search, not a folder one.
Selection is global: it survives filtering, navigation, and root switches. Zero results, empty folders, and the root list each state the condition in one line plus the key that escapes it; none of them clear the selection panel.
RUNTIME ADD — ^g a
A 78-column sheet centred over the dimmed session (34% opacity, still live). It is the picker with three differences: open repos are listed but locked [·] with their pane number, marks are [+] because they append rather than order, and the master never changes.
⇧⇥ cycles configured roots in place. The + affordance lives in the status bar next to the pane summary — clicking it opens the same sheet. No corner buttons, no divider handles.
KEY MAP — MOUSE PARITY
↑↓ / j k move cursor hover space toggle repo click row l ⇥ → enter folder click name h ← go up click .. ~ / g home · root click crumb a A all · recurse click count m set master click no. x X remove · clear click [n] / filter click filter ⏎ launch click button esc clear · quit click away
Picker keys are bare — no ^g prefix, since no terminal has focus yet. Inside a session everything stays prefixed, so ^g a is the only new session binding; a, m, x, and / are picker-local and never reach a shell.
Reserved by the session and never reused by the picker: ^g z, ^g c, ^g [, ^g 1-4, ^g q.
RESPONSIVE
≥120 cols master 70% / stack 30% 100–119 stack fixed at 34 cols, previews drop to 9 rows <100 stack hidden, one-line pane strip on row 1 <30 rows previews reduce to 2, then to the strip
The status bar drops shortcut labels before keys, then collapses to ^g j/k · 1-4 · z · [ · ? · q. Workspace name is the last thing to go.
COLLAPSING A PREVIEW — ^g c
Collapse is vertical only; the stack never changes width. A collapsed pane loses its box and its cwd and becomes a single title row on #101317 — disclosure marker ▸, number, name, status dot, and its last meaningful line (bundled 1.2s, idle 6m, exit 1). Open panes show ▾.
Freed rows redistribute to the panes still open, so one open preview grows to fill the column. ^g c toggles the selected pane; on the master it collapses every preview at once. ^g 2-4 promotes a collapsed pane directly — it expands as it takes the master frame.
Collapse state persists per workspace and survives promotion. Below 30 rows the stack auto-collapses from the bottom up rather than shrinking panes past 6 rows.
